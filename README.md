# ENGLISH DASH (kakkun-minigame)

キャラクターを前に倒し続けて走ると英単語(意味+音声)が流れてくる、1000mでテストが始まる英語学習ミニゲーム。

## 遊ぶ
GitHub Pages: https://kakkun15.github.io/kakkun-minigame/
(Settings → Pages で公開ブランチ/`/ (root)` を設定すると有効になります)

## 遊び方
`index.html` をブラウザで開くだけ(スマホ・PC対応、ビルド不要)。

### 1. RUN (0〜1000m)
- `↑` / `W` / `Space` を押し続ける(スマホは画面長押し)= 前に倒す。倒し続けるほど加速、離すと減速。
- `←` `→`(スマホは押したまま左右スワイプ)でレーン移動。
- 単語カード: くぐると GET(発音+意味+例文)。
- QUIZゲート: 英単語が出たら、正しい意味のゲートをくぐれ。正解=BOOST&コンボ、不正解=CRASHで大減速。
- コーン: ぶつかると転倒して減速。

### 2. TEST (1000m到達)
2×3 の6択から日本語の意味を選ぶ(全8問・ライフ3・1問12秒・コンボ倍率)。間違えた単語が優先して出る。
| 操作 | 内容 |
|---|---|
| 矢印 / WASD / マスをタップ | キャラ移動 |
| 左下 HINT(`Z`/`H`連打) | パンチングマシーン。Lv1:品詞・頭文字 → Lv2〜4:不正解を2/3/4個消去(点は減る) |
| 右下 JUMP(`Space`)を押している間 | 上昇。高いほど例文・訳がひらめく。半分で回答解禁 |
| 離す | 浮遊(ゆっくり落ちる) |
| もう一度押す | 沈み込み(溜め)。時間が倍速で減る。選んだマスの意味を入れた文が見え、正解なら自然な文、不正解なら崩壊した文。マスを移動すると溜め直し |
| 離す | マスに叩きつけて回答。溜めるほど高得点 |

`M` またはスピーカーボタンでミュート。
