# ENGLISH DASH (kakkun-minigame)

キャラクターを前に倒し続けて走ると英単語(意味+音声)が流れてくる、1000mでテストが始まる英語学習ミニゲーム。

## 遊び方
`index.html` をブラウザで開くだけ(スマホ・PC対応、ビルド不要)。

### 1. RUN (0〜1000m)
- `↑` / `→` / `Space` を押し続ける(スマホは画面長押し)= 前に倒す。倒し続けるほど加速、離すと減速。
- 単語カードが流れ、通過すると英語の発音と日本語の意味・例文が表示される。

### 2. TEST (1000m到達)
2×3 の6択から日本語の意味を選ぶ(全8問)。
| 操作 | 内容 |
|---|---|
| 矢印 / WASD / マスをタップ | キャラ移動 |
| 左下 HINT(`Z`/`H`連打) | パンチングマシーン。ゲージを上げるほどヒント深度UP(Lv1:品詞・頭文字 → Lv2〜4:不正解を2/3/4個消去) |
| 右下 JUMP(`Space`/`X` 長押し) | 長く高く跳ぶほど例文・訳が「ひらめく」。高さ50%で回答解禁 |
| ジャンプ中に `↓` 長押し(スマホはボタンを下へドラッグ) | 沈み込んで攻撃力アップ。選んだマスの意味を入れた文が見え、正解なら自然な文+近い単語、不正解なら崩壊した文になる |
| `↓` を離す(指を離す) | 叩きつけ=回答。`Space`を先に離す/ボタンから大きく外して離す=キャンセル |

`M` またはスピーカーボタンでミュート。
