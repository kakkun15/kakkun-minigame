# kakkun-minigame

## かぜはしり — 風になれ。

走るのが気持ちいい横スクロールのランゲームです。`index.html` をブラウザで開くだけで遊べます(インストール不要・1ファイル)。

### あそびかた
| 操作 | キーボード | スマホ |
|---|---|---|
| ジャンプ(空中でもう1回できる) | スペース / ↑ / W | 画面の右側をタップ |
| スライド / 急降下 | ↓ / S | 画面の左側をおしっぱなし |
| 音のオン・オフ | M | 右上のボタン |

- 長押しで高く、短く押すと低くジャンプ
- 空中で ↓ を押すと急降下。そのまま着地すると **ダイブ着地** で加速
- 光る玉を連続で取るとコンボ。10コンボごとに加速
- 水色の `>>>` を踏むとブースト
- 箱は跳びこえ、黄色い看板はスライドでくぐる(ぶつかると減速)
- 穴に落ちたら終わり。どこまで遠くへ走れるかを競います

### 気持ちよさのための工夫
- 歩幅と足の動きを走った距離に合わせているので、足がすべって見えない
- スピードが上がるほどカメラが引いて、集中線・残像・風の音・BGMのテンポが強まる
- スカーフのなびき、着地の土ぼこり、ぶつかった瞬間の一瞬の停止とカメラの揺れ
- 走った距離に合わせて昼 → 夕焼け → 夜 → 朝焼けと空が変わる
